# AKIRA — brand site

Single-page scroll site for AKIRA, the Japanese ramen restaurant in Kolkata
(アキラ · est. 2026). Built with Vite + React, plain CSS, zero runtime
dependencies beyond React.

## Develop

```bash
cd akira-site
npm install
npm run dev
```

## Build

```bash
cd akira-site
npm run build   # outputs to akira-site/dist
```
